# MySQL-ECommerce-Analytics
# E-Commerce Revenue & Customer Behavior Analytics (MySQL)

## Project Overview
Analyzed relational database of an e-commerce platform using MySQL Workbench to drive insights on customer retention, revenue growth, and inventory management.

## Tech Stack
- Database: MySQL Workbench 8.0
- Key Features Used: CTEs, Window Functions (DENSE_RANK, LAG), Joins, Aggregations, MySQL Views.

## Key Insights Found
1. **Revenue Trends:** Top 15% of customers contribute to over 60% of total company revenue.
2. **Product Performance:** Identified 8 high-stock products with low sales volume (unsold inventory risk).
